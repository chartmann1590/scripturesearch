# ScriptureSearch

Find and compare Bible verses across translations. Free, fast, offline.

![Android](https://img.shields.io/badge/Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)
![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=for-the-badge&logo=kotlin&logoColor=white)
![MIT License](https://img.shields.io/badge/License-MIT-green.svg)

## Features

- **Powerful Search** — Search by keyword, verse reference, or topic with instant results across multiple translations
- **Multiple Translations** — Compare verses side by side across different Bible versions
- **Study Tools** — Save favorite verses, share passages, create reading lists, and bookmark important passages
- **Audio Bible** — Listen to any verse or chapter with text-to-speech in multiple languages
- **Clean Interface** — Simple, distraction-free design with dark mode support
- **Offline Access** — Download translations for offline reading; no internet required after setup
